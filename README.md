# SAGEL™

A disruptive streetwear-meets-ethnic fusion storefront rework for the Gen-Z ritual dressing label SAGEL™.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The interface is front-end first and includes functional collection filters, product details, image zoom, size guidance, cart state, free-shipping progress, VIP sign-in and UPI/COD checkout handoffs.
